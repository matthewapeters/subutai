# Specialist Handoff Template

Use this template when a specialist returns work product to the orchestrator or another dependent task.

## Task summary

- What problem was examined
- What portion of the user request this handoff covers

## Key findings or decisions

- Material decisions
- Important trade-offs
- Risks accepted or deferred

## Open questions or blockers

- Questions the user should answer before execution continues
- Unresolved technical blockers

## Recommended next steps

- Immediate follow-on actions
- Which expert or task should act next

## Output files or artifacts produced

- Files created or modified
- Notes, plans, scripts, or reports generated

## Dependencies for downstream tasks

- Required inputs
- Ordering constraints
- Parallelization notes
