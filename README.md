# subutai

[![Portrait of Subutai from Wikipedia](https://upload.wikimedia.org/wikipedia/commons/thumb/3/38/Subudei.jpg/250px-Subudei.jpg)](https://en.wikipedia.org/wiki/Subutai)

**subutai** is named for [Subutai](https://en.wikipedia.org/wiki/Subutai), the Mongol general and chief strategist who helped Genghis Khan and Ogedei Khan coordinate campaigns across vast distances with unusual precision and discipline.

The project aims to channel that same idea into software: a reliable second-in-command agent experience that can help users plan, coordinate, and execute effectively.

Reference: [Subutai - Wikipedia](https://en.wikipedia.org/wiki/Subutai)
